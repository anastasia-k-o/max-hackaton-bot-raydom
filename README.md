# max-hackaton

Афиша мероприятий «Рядом» для мессенджера MAX.

| Каталог     | Что внутри                                                  | С чего начать                  |
|-------------|-------------------------------------------------------------|--------------------------------|
| `bot/`      | Чат-бот MAX на Go: уведомления, кнопки, статус диалога      | `bot/docs/QUICKSTART.md`       |
| `frontend/` | Мини-приложение на React + Vite, пока работает на моках     | `frontend/README.md`           |
| `backend/`  | Core Backend на Go + SQLite: записи, очередь, напоминания    | `backend/README.md`            |

## Запуск всей системы

Нужны Docker с плагином compose и make. Все настройки — один файл `.env` в
корне репозитория.

```bash
make up      # собрать и поднять: мини-приложение, Core Backend, бот
make down    # остановить (база Core Backend сохраняется в томе)
```

| Сервис | Адрес | |
|---|---|---|
| мини-приложение | http://localhost:4173 | nginx; `/api` проксируется в Core Backend |
| Core Backend | http://localhost:8090 | SQLite в томе `core-data` |
| бот | http://localhost:8080 | по умолчанию `MAX_MODE=mock`: сообщения в `GET /dev/max/messages` |

### Проверка в MAX

Как запустить весь сервис? (вам нужна ветка dev)

Взять .env.example, скопировать его в .env, и заполнить недостающие фрагменты (всё в корне проекта)

//ваш ID в MAX
DEMO_MAX_USER_ID=

//ссылка по которой будет работать мини-приложение (я делал через Tuna)
MINI_APP_URL=

//токен бота в MAX
MAX_BOT_TOKEN=

//установка сертификата минцифры в bot/certs
Выполнить скрипт в корне проекта:
bash bot/scripts/max-install-ca.sh

Далее прописываете make up, всё приложение поднимется (все контейнеры докера)

Далее открываете бота, можете ему что-нибудь написать, он отправит сообщение с кнопкой Открыть афишу, там можно на что-нибудь записаться, как запишитесь, в бота придёт уведомление.

Можно также выписать make scenario в консоли, он будет слать вам события с разными условиями (освобождение место, перенос, отмена и т.д.). Это чтобы прогнать все сценарии использования.
