# max-hackaton

Афиша мероприятий «Рядом» для мессенджера MAX.

| Каталог     | Что внутри                                                  | С чего начать                  |
|-------------|-------------------------------------------------------------|--------------------------------|
| `bot/`      | Чат-бот MAX на Go: уведомления, кнопки, статус диалога      | `bot/docs/QUICKSTART.md`       |
| `frontend/` | Мини-приложение на React + Vite, пока работает на моках     | `frontend/README.md`           |
| `backend/`  | Core Backend на Go + SQLite: записи, очередь, напоминания    | `backend/README.md`            |

## Запуск всей системы

Нужны Docker с плагином compose и make. Все настройки — один файл `.env` в
корне репозитория.

```bash
make env     # .env из .env.example, ключи между сервисами генерируются сами
make up      # собрать и поднять: мини-приложение, Core Backend, бот
make logs    # логи (make logs s=bot — одного сервиса)
make down    # остановить (база Core Backend сохраняется в томе)
```

| Сервис | Адрес | |
|---|---|---|
| мини-приложение | http://localhost:4173 | nginx; `/api` проксируется в Core Backend |
| Core Backend | http://localhost:8090 | SQLite в томе `core-data` |
| бот | http://localhost:8080 | по умолчанию `MAX_MODE=mock`: сообщения в `GET /dev/max/messages` |

### Проверка в настоящем MAX через Tuna

Мини-приложению MAX нужен публичный HTTPS-адрес. [Tuna](https://tuna.am)
даёт его вашему компьютеру без сервера.

1. В `.env`: `MAX_MODE=real`, `MAX_BOT_TOKEN=…` (этот же токен Core Backend
   использует для проверки входа), `DEMO_MAX_USER_ID=<ваш id>`. Если MAX
   требует сертификат Минцифры — `bash bot/scripts/max-install-ca.sh` и любое
   непустое `MAX_CA_FILE`.
2. `make up`.
3. В отдельном терминале: `tuna http 4173` — Tuna покажет публичный
   HTTPS-адрес. Откройте его в браузере: должен появиться экран «Откройте
   афишу в MAX» — так мини-приложение выглядит вне MAX.
4. В `.env`: `MINI_APP_URL=<адрес Tuna>/app`, затем снова `make up` —
   пересоздадутся бот и Core Backend с новым адресом.
5. Этот же адрес (без `/app`) должен быть указан как адрес
   мини-приложения бота в MAX — это делает владелец бота там, где бот
   зарегистрирован. Тогда мини-приложение открывается внутри MAX с
   `initData`, и Core Backend узнаёт пользователя. Кнопки в сообщениях
   бота открывают его внутри MAX при `MAX_MINIAPP_BUTTON=open_app`; при
   `link` — в браузере, где мини-приложение попросит открыть его в MAX.

Если привязать мини-приложение к боту вы не можете (это делает владелец
бота на партнёрской платформе MAX), поставьте в `.env` `DEV_MODE=true`,
`VITE_DEV_LOGIN=true` и свой `DEMO_MAX_USER_ID`, затем `make up`. Тогда
мини-приложение, открытое в браузере — по адресу Tuna или по кнопке
«Открыть афишу» из бота, — входит под вашим аккаунтом MAX, и бот пишет вам
о записях, которые вы делаете в браузере. Любой, кто знает адрес туннеля,
тоже войдёт под этим аккаунтом, поэтому для показа жюри верните
`VITE_DEV_LOGIN=false`.

На бесплатном тарифе Tuna адрес меняется при каждом запуске — повторяйте
шаги 4–5. Инструменты `/dev` через туннель закрыты (nginx отвечает 404),
локально они работают на `http://localhost:8090/dev/...`.

Проверка цепочки в MAX без ожидания: `make scenario` (подробно —
`backend/README.md`). Без Docker каждый сервис запускается из того же `.env`:
`make run-core`, `make run-bot`, `make run-front` в трёх терминалах.
`make help` — все команды.

## CodeGraph

Для навигации по коду агентами подключён [CodeGraph](https://github.com/colbymchenry/codegraph).
Индекс у каждого свой и в git не хранится. Один раз после клонирования:

```bash
curl -fsSL https://raw.githubusercontent.com/colbymchenry/codegraph/main/install.sh | sh
codegraph init        # строит .codegraph/ в корне репозитория
```

Настройки агентов уже в репозитории:

| Агент       | Файл                  |
|-------------|-----------------------|
| Claude Code | `.mcp.json`, `CLAUDE.md`, `.claude/settings.json` |
| Codex CLI   | `.codex/config.toml`  |
| остальные   | `AGENTS.md`           |

`.claude/settings.json` сразу включает сервер `codegraph` и разрешает его
инструменты (они только читают индекс). Проверить: `/mcp` в Claude Code.

Cursor, VS Code и JetBrains хранят путь к проекту абсолютным, поэтому их
настройки локальные: выполните `codegraph install` и выберите свой редактор.
